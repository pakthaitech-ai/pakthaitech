DESIGN

2. Receive it at a dedicated Worker route, protected by a high-entropy CRISP_WEBHOOK_SECRET; website hooks are unsigned, so reject missing/incorrect secret.
3. Validate website_id equals 5787d483-b0e3-4627-b50d-5e6c9ae5b86b, event equals message:send, data.from equals user, and data.type equals text.
4. Send a concise internal alert containing the visitor's message and session reference to a separately configured CRISP_ALERT_WHATSAPP_NUMBER.
5. Log send status without exposing access tokens or webhook secrets. Return HTTP 2xx only when the hook is accepted/handled. Ignore operator messages and other websites.
6. Crisp continues to receive all chat messages normally. This is notification only; it does not move the conversation, send an automatic customer reply, or authorize a purchase.
